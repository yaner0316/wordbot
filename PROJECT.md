# WordBot Project Constitution

## Purpose

WordBot is a child-facing English vocabulary learning and formal assessment system. It is usable only when a real production user can log in, obtain a complete formal quiz, answer and submit it, receive grading, persist assessment evidence, and later see consistent results and history.

This file is the authoritative product and domain rule set. `AGENTS.md` governs engineering execution; `docs/OPERATIONS.md` governs production and data operations. Dated plans, handoffs, audits, and subsystem designs provide evidence but cannot override this file.

## Canonical domain model

- New entries from every public client and API must select specific senses offered by the dictionary lookup. Batch input must resolve every word before submission. Handwritten meaning fields and bare-word submission are not valid entry paths. The server validates a learner/word/sense-bound selection receipt and derives the stored meaning and part of speech from it; a client boolean is not proof of selection. Existing meaning text is not freely editable through user-facing update endpoints. A lookup failure preserves the input for retry and never falls back to a guessed, blank, or self-repeated meaning. This applies to new input, not a retroactive rewrite of stored words.

- The learning and cache unit is one user's one meaning, identified by canonical `user_id + meaning_id` (`words.id`; older code may call it `word_id`). Different meanings of the same spelling remain independent.
- The user account's current selected learning level controls every generated and selected formal question. A meaning's historical entry level is metadata, not an eligibility filter and not a generation level.
- New accounts persist junior-high difficulty (displayed as “初中”, stored as “中学”) at registration; setting this initial default is not a difficulty change. Changing the account difficulty uses the new level for future questions while preserving existing scores, assessments and immutable historical question snapshots. Cache rows referenced by history remain readable even when retired from future selection.
- A deleted meaning is absent from the current library, progress totals, new challenges, reviews and generation coverage. Parent deletion archives the meaning with `deleted_at`, preserving its identity, past assessments, scores and immutable challenge snapshots. Existing challenges remain readable/submittable; submission never restores the archived meaning. Re-entering the same spelling creates a new meaning and entry time. Every active meaning that is not mastered is a coverage target, including unseen, recognized, consolidating, pending, and legacy status variants.
- Production persistence is Supabase. Compatibility adapters may translate legacy shapes at boundaries, but may not become a second source of truth.

## Current question policy — context-learning-v3

This is the sole active generation and approval policy. It supersedes blind-completion-v5 and earlier, unique-answer-v2 and earlier, question-content-v1, the two-blind-review flow, the all-four-completions-grammatical rule, and the all-six-pairs semantic-separation veto. Dated reports and old migration files are historical evidence, never alternate executable policies.

- The learning task is selecting the only English option that fits the stated context in the selected sense. A more typical answer is insufficient when another ordinary reading also fits. Do not add unstated motives, actions or background to rescue a distractor; do not invent restrictions to exclude a supported alternative.
- Generation order: English stem → stem review → distractors → ONE blind option review → option glosses and sentence translation → translation review. These are three distinct review responsibilities, not three repeated uniqueness reviews. A rejected earlier stage stops downstream work.
- Stem review checks complete grammatical and natural sentences, actual selected sense and POS, target inflection, level, accessible meaningful clues and unnecessary reading burden. There is no word-count limit, including no 100-word limit. Primary lower uses familiar concrete scenes, common support words and simple inference; primary upper permits richer familiar scenes and clear cause/contrast/time relations. Target noun number changes are allowed in both primary bands; target verbs keep the supplied form. Junior-secondary and higher permit grammatical inflection of the same lexical entry and sense.
- Distractors prefer suitable learner-library words, especially previously studied entries, supplemented by other words. Same-POS words, spelling/shape lookalikes, antonyms, semantic-topic candidates and natural phrases are allowed, with no mandatory category quota. Different POS may legitimately fail a blank. A malformed word or phrase is not a valid distractor. The whole question must still require understanding meaning, rather than being solvable entirely by POS or formatting. Identical English options are invalid; two excluded wrong options may have identical, synonymous or inclusive meanings.
- The blind reviewer sees printed English completions and the learner-level rubric, never the intended answer, Chinese glosses or generator reasons. It evaluates all ordinary meanings of every option and provides grounded fit/exclusion, grammar, real-word/phrase and difficulty evidence. Exactly one fit must equal the stored key. The parser rejects missing, uncertain or explicitly contradictory evidence; this is not a guarantee of arbitrary natural-language model correctness.
- Translation review checks the selected meaning against actual target usage/POS, genuine option glosses, and faithful natural sentence translation: actors, actions, negation, quantities, time, causal relations and no added details. Wrong English sense requires fixing the stem, not relabeling Chinese. No option-pair overlap veto is permitted.
- Repairs carry the rejected version and concrete evidence to the affected generator. Stem changes invalidate every downstream artifact; option changes invalidate uniqueness and gloss review; translation-only changes preserve valid stem and option proofs. A retired-policy checkpoint, including old lexical bans and repair feedback, cannot resume under this policy.
- New selection, generation coverage, single/pair publication and new challenge snapshots require the current policy and input-bound three-part evidence. Old approval flags and published-cache compatibility do not bypass these gates. Historical assessments and already-created challenge snapshots remain readable/submittable without rewriting them. Old ready rows are excluded from future supply, not bulk deleted. Normal replenishment may temporarily leave supply below the target after activation.
- Changing these rules requires updating the central policy version and its database publication/selection barrier together, with regression tests for the retired behavior. A local edit alone does not retire the production deployment; activation requires coordinated migration, backend/frontend release and live verification.

- Translation policy `question-content-v3` supersedes v2: each of the four option glosses must match the printed form, active/passive voice, part of speech, object and collocation in the actual sentence. A dictionary-valid but contextually wrong sense fails. Distractors remain wrong: do not invent motives/actions/background or alter their actual part of speech to make them fit. When the slot is grammatically incompatible, retain the option’s genuine lexical meaning/POS. Required calibration: `had protected them` → 保护, not 受保护的; `slap a coin` → 拍打, not 扇耳光; `I must _____ ...` + `success` → 成功（名词）, not 成功做到. Wrong options can share meanings without a translation veto. Old v2 translation evidence cannot approve; valid upstream stem/option proofs remain reusable.

## Formal-question supply invariants

- Collision exclusions are hard bans during the unresolved candidate's repair lifecycle, including resumed attempts and capitalization variants. They are separate from the one-word sibling reuse allowance. Grammar defects in the correct completion replace the context even when the review is uncertain; changing the context invalidates its old translation and downstream proof. Explicit reason/decision contradictions cannot approve a new question. Concrete rejection evidence is carried to the relevant generator; heuristic recognition of explicit contradictions is not a proof of arbitrary natural-language consistency.

- Every coverage target must maintain two distinct, current-policy, AI-approved type-1 formal questions at the user's current learning level whose stems are absent from that meaning's active display history. A ready cache row or a completed generation job alone does not prove this fresh-question reserve exists.
- Recording a formal display durably enqueues replacement work in the same database transaction. Replenishment starts after consumption, while the meaning is cooling, without requiring the child to open another challenge. Mastered/deleted meanings remain excluded by the enqueue and worker guards. Existing fresh approved siblings and valid partial work are reused; generate only the missing supply.
- Distinctness requires different normalized stems and fingerprints. The approved pair must also satisfy the current distractor-overlap, option, Chinese-meaning, exact context-translation, and semantic single-answer rules.
- A formal quiz is cache-first and fail-closed: it uses only valid cached questions and never silently falls back to live generation or an unapproved/stale row.
- Type-1 fill-in stems for formal challenges and self-selected practice must be English. Shared deterministic admission rejects stems containing Han characters or no ASCII English letters, regardless of AI approval, cache readiness, or legacy audit compatibility, including generation candidates without a blank. This check applies only to the stem, not Chinese translations, meaning labels, teaching analysis, or type-4 recall prompts. It does not rewrite completed assessment history.
- Target inflection follows the user's current learner level: primary permits noun singular/plural changes only and keeps verbs in the supplied form; junior-secondary and higher permit grammatical inflections while preserving the selected lexical item, sense and part of speech. This does not permit synonyms or derivational word substitution. Generation keeps the canonical entry separate from the printed target form through blanking, options and checkpoint resume. The stem review verifies changed forms and the primary restriction. Sentence length remains unrestricted by word count.
- New semantic audits include one grounded sentence clue, the correct option's contextual reason, and all four options' contextual meanings and fit/exclusion reasons. Audit judgments must agree on one answer; an approval flag alone is insufficient. Validated teaching analysis is prepared and persisted with the cache before display, then copied into immutable challenge and assessment snapshots. Result/history reads never generate explanations after submission. Option reasons are keyed by option word, so changed letters cannot misalign them.
- Semantic review independently judges all four completed sentences without seeing the intended answer. A merely more common interpretation cannot exclude another plausible completion. New-method evidence is bound to the exact context and option identities; a checkpoint from a retired policy is discarded, while current-policy partial work resumes at the earliest invalid stage. If the context itself is non-unique, replacement must add a distinguishing stated clue rather than repeatedly reuse that rejected stem with different distractors.
- Coverage is continuously reconciled. Missing, stale, wrong-level, invalid, or incomplete supply creates or revives durable generation work without requiring a user or operator to notice it first.
- A target generation failure is never terminal. Retries continue with bounded backoff until the target is ready, mastered, or deleted. Attempt counts and safe diagnostics remain observable but do not remove a target from the executable queue.
- Approved partial work and valid intermediate stage artifacts are durable. Retry resumes at the first missing or invalid stage. A changed input invalidates that stage and its downstream dependents only; it does not rerun unrelated valid upstream work or discard an independently approved variant.
- Self-selected missing-question requests take priority over background replenishment across accounts, with fair user rotation within each class. An unserved request retains priority until claimed; its claim consumes that priority, and failures then follow normal retry timing.
- Complete pairs publish atomically. A fully audited current-policy question may publish separately for self-selected practice while its existing generation job continues to replenish the second variant; only the complete pair finishes that job. Partial publication never replaces an existing usable active question or retires other cache rows. Formal tests still require two valid ready variants. Self-selected practice may start with one already-published, available, current-level, policy-compatible approved question per meaning, without waiting for a second reserve question. All individual question quality and audit gates still apply; retired rows and unpublished generation checkpoints remain unselectable; only the fenced publication path may expose a completed checkpoint question. Formal selection and background pair replenishment retain their two-question requirements.

## Learner-level language fit

- “小学低年级” means grades 1–3 and “小学高年级” means grades 4–6 (stored as the existing “小学” value); “中学” refers to junior-secondary completion (level 3, grades 7–9). The existing CET4_6_TOEFL combined band uses general college reading with supported academic contexts; it does not certify a particular CET/TOEFL score or silently select the hardest exam. Each band has its own versioned rubric, grammar guidance and authored examples.
- “高中” uses completion of compulsory and selective-compulsory senior-high English as its reference audience. The target word/sense may be new; understanding the context, decisive clues and distractors must not depend on additional unsupported specialist vocabulary or knowledge.
- Generation and new approvals use each band’s local rubric, grammar summary and WordBot-authored calibration examples. High-school vocabulary lookup uses the verified 2025 appendix; junior-secondary lookup uses its unstarred compulsory-education entries. Primary and combined-college bands have no verified complete local lookup: review actual language against their rubric without pretending that an absent list identifies unknown words. No runtime curriculum download is required. Wordlist misses are review hints, not a whitelist rejection; familiar spellings must still be judged in their actual sense and collocation.
- Judge vocabulary burden, syntactic comprehension, inference/background knowledge and all distractors. There is no sentence-length/clause-count ceiling, one-new-word quota, or topic ban. Names, transparent derivations and incidental unfamiliar terms are acceptable when comprehension remains accessible. A stated blocking barrier or unresolved grounded concern requires revision; missing/inconsistent evidence cannot approve a new question.
- Fit evidence is bound to the exact context, option layout, target sense and current level, and is persisted with the existing teaching analysis. Saved examples used in new questions receive the same review. Within the current question policy, changed-input checkpoint audits are rechecked while retaining valid upstream work; only affected stages are regenerated after a concrete rejection.

## Word and phrase entry

- When the dictionary identifies a likely typo, both entry forms show the suggested spelling and its independently looked-up senses. Choosing a sense and confirming saves the suggested spelling. Ambiguous input stays editable. Selection receipts bind to the offered spelling.

- Child and parent entry preserve complete English words and phrases, including internal spaces. Entry separators are newlines, commas and semicolons; spaces inside a phrase never silently split it into separate words. Consecutive whitespace within a phrase is normalized to one space.
- A line using “word or phrase | Chinese meaning” remains one entry and preserves punctuation in its Chinese meaning. Both entry forms use the same parsing rule and pass the full phrase through lookup, submission and persistence. Explicit individual words such as “the” and “to” remain valid; the parser does not add stop-word filtering or guess the original phrase.

## Chinese meaning labels

- Saved Chinese meaning labels use short translation words/phrases, usually 2–8 characters and at most 20 characters including punctuation. Preserve the selected concept; use a short qualifier when needed. Do not store definition paragraphs, examples or encyclopedia explanations as the Chinese label.
- Multiple concepts already present in a legacy label are retained as separate short phrases; shortening never creates, merges or deletes meaning identities. The original English definition remains intact. Immutable historical assessment text is not rewritten for presentation changes.
- Automatic translation, new word creation, parent edits and translation backfills enforce the same cap. An oversized provider value fails quality validation instead of being truncated or saved; a manual oversized label receives an actionable validation error.

## Learning and mastery invariants

- Random challenges show only system preparation/eligibility and start automatically when ready; they do not show the word picker, selection counts or replacement actions. Cancelling or retrying random preparation does not switch to self-selected practice.
- Newly created wrong-answer review rounds randomize the eligible questions before persistence, avoiding the source order when more than one question remains. Resuming an existing round preserves its saved order, answer mapping and original score. Demo review follows the same ordering rule.

- The homepage offers system-random formal challenges and self-selected practice to children and parents. Every self-selected challenge, including automatically filled places, is practice: it preserves grading and history but never changes formal mastery, progress, cooldown, formal selection priority, or game minutes. The server enforces this classification. Practice may use cooling meanings and repeat practice stems; formal tests cannot reuse a stem already shown in practice. Selection uses owned meanings across pending, recognized and consolidating meanings. The picker hides definitions and groups equal spellings: choosing a word chooses all its non-mastered meanings together, each counting as one question. Parents do not need to authorize the child's selection.
- A challenge contains up to ten distinct eligible meanings. In self-selected practice a user may specify zero to ten, and the server randomly fills the remaining places from the same eligible pool. Explicit choices are never silently replaced. A library with fewer than ten non-mastered meanings allows a complete short challenge. Cooling meanings and missing supply never reduce the intended size.
- Every first-time formal challenge requires at least 18 hours from word entry. Previously displayed meanings also require at least 18 hours from their last formal display; eligibility uses the later of entry and display. All selection and creation paths enforce ownership, saved mastery and the user's current learning level.
- A cache shortage preserves the chosen meanings, requests durable supply and keeps the challenge in a preparation state with automatic retries for at most two minutes per attempt. The picker names missing English words without definitions, allows explicit whole-word replacement while retaining other choices, and stops automatic waiting at the deadline while preserving the full set for retry. Missing selected supply gets a two-minute within-user queue priority and at most one backoff advance per five minutes; active leases, valid checkpoints and cross-user rotation remain intact. Formal quality gates remain unchanged. Supply is prepared ahead of the next eligible challenge; elapsed time alone is not proof of readiness during infrastructure failures.
- A system-random formal round selects at most ten distinct meanings. Old and new are judged by meaning, not spelling, and not by the previous learning day. A meaning is old once this child has at least one submitted, scored formal answer for it, whether that answer was correct or wrong. Self-selected practice and display-only history do not make a meaning old. Display history still excludes stems and enforces the 18-hour cooldown. Select only unmastered meanings that have cleared cooldown, match the current level and question policy, and can actually be issued with an unused approved stem. Within each priority below, a meaning tested or displayed on the previous Asia/Shanghai learning day comes first; that preference never makes a separate short round. The order is: old meanings whose latest formal answer was wrong; old meanings that were wrong before but whose latest formal answer is correct; old meanings formally tested and never wrong; then meanings with no formal answer. Earlier wrong meanings stay ahead of new meanings. If fewer than ten meanings qualify in an earlier group, fill the remaining places from the later groups. A round does not end early because the previous learning day has only a few meanings left. After submission, the next round is chosen again from the updated answers, displays and mastery, and a retest must use a different stem. Do not repeat a stem or relax the quality gate to fill a paper. A genuinely small unmastered library may still be a complete short challenge. When cooldown or issuable supply is below the intended size, keep the full intended count and the existing cooldown or preparation result; do not present the shortage as a complete ten-question paper. The candidate count, the round size shown to the child, and the issued paper use that same intended size.
- Replacement generation excludes stems in active formal display history, including otherwise approved checkpoint rows and saved entry contexts. Retain valid unpublished work, but regenerate a displayed context and its dependent stages rather than republishing an unusable old pair.
- Complete short challenges persist assessment and mastery progress normally, but never add or deduct game minutes. Their stored questions carry the exact intended count so truncated legacy ten-question sessions are not mistaken for complete short challenges.

- Initial selected-sense context and recognition review are preparation, not formal mastery evidence. Submitting a real initial context establishes the recognized stage (whether correct or wrong) with zero formal mastery evidence; it must not remain pending. Only meanings without a submitted real learning attempt are unseen/pending. Preview, test, unsubmitted, and explicitly non-real records do not establish learning. Later formal evidence determines consolidating/mastered under the rules below.
- Automatic new mastery requires two consecutive correct formal assessments on two different normalized stored stems, separated by at least 18 hours and no more than 720 hours.
- Before mastery, a formal wrong answer resets that meaning's consecutive sequence. Missing stems, cosmetic duplicates, preview/test/review rows, and duplicate submissions do not prove new mastery.
- Saved mastery, including an explicit parent mark, stops formal question selection and generation. Later automatic recalculation or an in-flight submission must not revoke it; deliberate parent edits remain available. Manual mastery does not fabricate passed assessments.
- The three visible learning stages are entered, consolidating, and mastered, counted per active meaning. Entered means no submitted valid learning attempt. Consolidating includes initial learning and formal attempts of either outcome until mastery. Mastered retains the existing mastery rule and parent override. The existing saved recognized and consolidating states both map to visible consolidating. Evidence is a fallback for legacy records without a valid saved stage; formal submissions still update progress from immutable evidence.
- The 2026-09-05 23:00 Asia/Shanghai rule change is forward-only: mastery earned under the prior rule at that cutoff is retained. The authorized recovery merges that baseline with later learning and current saved progress across every user; it never replaces current progress with an old snapshot or rewrites answers.
- A spelling is mastered only when all of its meanings for that user are mastered.
- Assessment answers are historical evidence and are not rewritten to force a desired state. Derived status and rewards are reconciled from canonical evidence.
- History offers the existing wrong-answer review chain: resume the latest unfinished round, report no wrong answers/completed/archived-only states, and never recreate an already completed chain. Each active meaning appears once; archived meanings remain excluded both during restoration and submission. Reviews preserve the original first score and never adjust game minutes.
- Game-time adjustments follow successful persistence of a complete, real, ten-question formal quiz: 10/10 adds 10 minutes, 9/10 adds 5 minutes, 6–8/10 makes no adjustment, and 0–5/10 deducts 5 minutes. Practice, test and review rounds do not adjust game time; retries and duplicate submissions must not apply the adjustment twice.
- Mastery progress and newly mastered feedback follow the independent mastery evidence rules above. Quiz scores determine game time, not mastery; newly mastered feedback does not introduce a separate reward formula.

## Authorization and consistency

- The server is authoritative for identity, role, quiz state, grading, mastery, and rewards.
- Leaving the parent console for a child-facing page, including browser-back navigation, must first downgrade the server session to the child role and clear in-memory parent credentials. Reloading a remembered account must confirm this downgrade before loading the child homepage. If downgrade cannot be confirmed, remain on the parent page and offer a retry; an explicit unauthenticated response clears the expired local identity and returns to login. Navigation alone must not leave parent authority active.
- Children may add their own words/meanings through the supported learning entry (`POST /api/words`), perform the explicitly supported learning flow, and read their allowed state. Editing or deleting existing words/meanings, user settings, destructive cleanup, and review-flag changes are parent-only writes.
- Parent word management supports selecting individual meanings and all currently loaded rows. Deletion requires confirmation, verifies ownership for the entire request and is idempotent; a request contains at most 100 IDs and the UI splits larger selections into batches. On partial failure, completed batches stay deleted and remaining selections stay available for retry. The entry timestamp appears beside the word in Asia/Shanghai time; missing timestamps are displayed as unknown, never replaced with an edit time.
- Cross-device writes use server revisions or compare-and-swap semantics. Duplicate submissions are idempotent.
- Child-facing errors are actionable but do not disclose provider payloads, credentials, internal job rows, or other users' data.

## Definition of done

A product change is complete only when all applicable statements are evidenced:

1. The authoritative rule and affected subsystem documentation agree.
2. Focused regression tests were observed failing before implementation and pass afterward; the relevant full suites pass.
3. Required migrations are versioned, repeatable, permission-checked, and verified without assuming that writing SQL means it was applied.
4. The intended `main` commit passed CI and deployment, and public health reports the same backend revision.
5. A real authorized production user completes the affected end-to-end flow, including durable persistence and readback. Tests, deployment status, or health alone are insufficient.

## Change control

Changes to learning semantics, coverage targets, question quality gates, authorization, production storage, or definition of done require an explicit user decision and a `PROJECT.md` update. Implementation details that preserve these invariants may evolve without duplicating the rules elsewhere.
