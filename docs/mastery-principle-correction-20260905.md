# Unified mastery correction — 2026-09-05

Each meaning requires two consecutive correct formal assessments with different stored question stems, 18–720 hours apart. A formal wrong answer resets the sequence for every word source. Missing stems, cosmetic changes and duplicate submissions cannot prove mastery. Every meaning must master before the word is marked mastered.

The selected-sense accumulating-evidence exception is removed. Initial learning contexts and recognition reviews remain preparation. Submission, queue selection, statistics, recovery planning and reconciliation use the shared evaluator and assessment adapter. Original answer records remain unchanged.

Validation: 18 dedicated principle tests, including complete 10-question submission sequences for both entry paths and interval boundaries. Full backend suite: 1086 tests, 1079 passed, 0 failed, 7 skipped. Tests were observed failing before implementation. The current frontend uses server states; its production quiz and app contracts were included in the suite, so no frontend code change is required.
