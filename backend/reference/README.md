# 高中适配本地参考

词表来源为《普通高中英语课程标准日常修订版（2017年版2025年修订）》附录 2，纸面页 73–129。下载地址、下载日期和原 PDF SHA-256 记录在 high-school-vocabulary-2025.json。使用公开 PDF 镜像；最初学校链接失效，因此不依赖该链接作为运行时服务。

提取使用 pypdf，取 PDF 零基页 75–131 的文本行，保留以英文字母开头的词条，去掉单字母章节标题，保留代词 I 并去重，保留原始星号和括号中的拼写变体。得到 3,099 条印刷词条行；课标说明为 3,100 个单词，词条行含组合词、缩略语与拼写变体，不宣称两者计数口径相同。没有并入后面的国家名称参考表。模块会提取词条中的英文形式，并将简单屈折变化仅标为可能匹配；这是提示工具，不是精确词形还原器。

课标注明未列出所有派生形式，不给出每个单词全部词义。命中或未命中均不能替代语境判断。high-school-fit-v1.json 的语法摘要参照附录 3 纸面页 133–137；审核规则和四个例句为本项目自编，例句仅校准语言负担，未声称为高考真题或经测量校准的完整选择题。

运行时只读取本地 JSON；不下载课标、不发送整个词表给模型。生成使用精简规则和正反例；词义审核的同一次请求补充词表查找提示和四维适配证据，不增加模型请求次数。真实消耗仍随输入输出 token 变化。
